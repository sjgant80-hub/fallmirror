"One mirror command pushes your repo to GitHub + Codeberg + GitLab + an IPFS pin + a USB stick on your desk. If any of them dies, the others persist. Your code outlives any single host."

fallmirror is a 200-line Node script. Run it after every commit. It pushes git push --mirror to every host you've configured, in parallel. Plus optional IPFS pinning and local USB backup. All from one command. No CI required — your laptop is the publisher.

Install · 60 seconds

gh repo clone sjgant80-hub/fallmirror
cd fallmirror

# show setup checklist
node fallmirror.mjs --setup

Then in your PowerShell session:

$env:CODEBERG_USER = "your-codeberg-handle"
$env:CODEBERG_TOKEN = "..."  # codeberg.org/user/settings/applications
$env:GITLAB_USER = "your-gitlab-handle"
$env:GITLAB_TOKEN = "..."     # gitlab.com/-/profile/personal_access_tokens
$env:FALLMIRROR_USB = "E:\fallmirror"   # optional
$env:FALLMIRROR_IPFS = "1"               # optional · needs `ipfs daemon`

# mirror current repo
cd path/to/any/git/repo
node /path/to/fallmirror/fallmirror.mjs

# mirror EVERY repo in a folder
$env:FALLMIRROR_ROOT = "C:\Users\you\code"
node /path/to/fallmirror/fallmirror.mjs --all

# check what was mirrored when, where
node /path/to/fallmirror/fallmirror.mjs --status

FAQ

Does this work with private repos?

Yes — Codeberg and GitLab both support private. Pass ?visibility=private when manually creating (or modify the script).

Do I need IPFS running?

Only if you set FALLMIRROR_IPFS=1. The default config is GitHub + Codeberg + GitLab — works without anything else installed.

What about LFS / large files?

v1.0 does standard git push --mirror. LFS works on GitHub + GitLab + Codeberg natively. USB mirror is bare-bone (no LFS pointer resolution).

Tokens stored in env vars feel risky.

The script reads them from process env — they never get written to disk. Use a credential manager if you want extra layers (Windows Credential Manager, 1Password CLI, etc.).

Combined with fallvault?

Yes — fallmirror handles your code (multi-host). fallvault handles your laptop's other files (encrypted single-HTML backup). Together: total emergency-recovery coverage.
